# Meeting Notes

## Naming

Formal meeting notes use `YYYY-MM-DD-<meeting-type>.md` in this directory:

- `YYYY-MM-DD-standup.md` — Tuesday quick sync
- `YYYY-MM-DD-progress-review.md` — Thursday progress review and planning
- `YYYY-MM-DD-kickoff.md` — kickoff meeting

Raw recordings and transcripts belong in `archive/` and are not the source of truth for decisions. Formal notes follow [`../MEETING_TEMPLATE.md`](../MEETING_TEMPLATE.md), and `MatDevstamp` is the note-taker for the project meeting notes.
